# Mi tienda

Proyecto web con HTML, CSS y JavaScript.

## Estructura

```
mi-tienda/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Cómo verlo

Abre `index.html` en tu navegador.

## Subirlo a GitHub

```bash
git init
git add .
git commit -m "Primer commit"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/mi-tienda.git
git push -u origin main
```

Para publicarlo gratis, activa **GitHub Pages** en *Settings → Pages* con la rama `main`.
